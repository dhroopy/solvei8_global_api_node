🔁 Push update to a factory's local machine

Sends an "update apis" event over MQTT — the factory's flovation-mqtt-listener service will stop, remove, pull the latest image, and restart its API container.

⚠️ This restarts live production infrastructure on the factory floor. The local API container will be briefly unavailable during the restart. Confirm the factory ID carefully before pushing.
